# Customer request insights

## Current coverage

No approved customer request or order dataset has been provided for this repository. The public Pages site is a preview and does not collect live orders; the order and payment modules are planned. The UX researcher must not report a “most common order” until real, authorized records are available.

## Researcher process

1. Record each approved source and date range. Review every available request in that scope, remove duplicates, and send identifying details only through approved private systems.
2. Have the customer-input role anonymize and categorize the records. Keep names, contact details, artwork, order IDs, and exact customer amounts out of this public repository.
3. Count each category and record the denominator, date range, unknown/uncategorized items, and sample limits. Separate direct requests from inferred needs.
4. Give the UX designer and program manager a summary of common requests, evidence, unmet needs, and security/privacy concerns. The design head checks that the recommendations match the data.
